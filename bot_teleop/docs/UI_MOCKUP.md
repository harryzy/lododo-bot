### 3.3 Costmap可视化

#### Costmap叠加层渲染规则
```javascript
// Costmap值范围: 0-254
// 0 = 自由空间（不渲染）
// 1-99 = 膨胀区（橙色半透明）
// 100-254 = 致命障碍物（红色半透明）

function renderCostmap(costmapData) {
  const canvas = document.getElementById('costmap-layer');
  const ctx = canvas.getContext('2d');
  
  for (let y = 0; y < height; y++) {
    for (let x = 0; x < width; x++) {
      const index = y * width + x;
      const value = costmapData[index];
      
      if (value === 0) {
        // 自由空间，跳过
        continue;
      } else if (value > 0 && value < 100) {
        // 膨胀区（橙色，透明度根据值递增）
        const alpha = value / 100 * 0.5; // 0-0.5
        ctx.fillStyle = `rgba(255, 165, 0, ${alpha})`;
      } else {
        // 致命障碍物（红色，半透明）
        ctx.fillStyle = 'rgba(255, 0, 0, 0.5)';
      }
      
      ctx.fillRect(x, y, 1, 1);
    }
  }
}
```

## 11. 响应式设计（桌面端）

### 11.1 窗口尺寸适配

**1920x1080 (全屏)**:
- 地图区域: 1496px × 980px
- 右侧面板: 400px
- 组件间距: 24px

**1280x720 (最小尺寸)**:
- 地图区域: 856px × 620px
- 右侧面板: 400px（保持不变）
- 组件间距: 16px

### 11.2 组件自适应规则

1. **导航栏**: 固定高度60px，宽度100%
2. **地图区域**: 自适应宽度（窗口宽度 - 400px - 边距）
3. **右侧面板**: 固定宽度400px，高度自适应
4. **视频流**: 宽度自适应（最大300px），保持16:9比例
5. **底部状态栏**: 固定高度40px，宽度100%
